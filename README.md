# AI Smart Waste Management — Vercel Frontend

This repository contains a Vercel-ready frontend for the AI Smart Waste Management System.

## Included

- Static landing page and dashboard UI
- Smart bin rule cards
- Demo analytics panels and mock predictions
- Vercel serverless routes for `/api/health`, `/api/stats`, `/api/rules`, and `/api/predict`

## Local preview

Open the project folder and run:

```bash
python -m http.server 8000
```

Then visit:

- http://localhost:8000

## Deploy to Vercel

1. Import this repository into Vercel.
2. Keep the default settings.
3. Deploy the project.
4. Your app will be live on a Vercel domain.

## Note

This is a Vercel-compatible frontend/demo deployment. It does not include the original Python FastAPI + SQLite + webcam ML backend logic for local execution. For the full production ML app, deploy the backend separately on Render, Railway, or another Python-capable host and connect it to this frontend.
